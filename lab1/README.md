# Лабораторная работа 1 (Задачи 1–3)

## Сборка (g++)
```
g++ task1.cpp -o task1 -fopenmp
g++ task2.cpp -o task2 -fopenmp
g++ task3.cpp -o task3 -fopenmp
```

## Запуск

### Задача 1 — идентификаторы потоков
```
task1.exe
```
Программа запрашивает число потоков. Ввести, например: `8`.
Программа выводит для каждого потока его идентификатор, общее число потоков и строку "Hello World!".

### Задача 2 — среднее значение по массиву
```
task2.exe
```
Программа запрашивает:
1. Число потоков (например, `8`)
2. Тип schedule: `static`, `dynamic`, `guided` или `runtime`

Вычисляет среднее по массиву 16000 элементов, выводит время и первые 10 элементов результата.
