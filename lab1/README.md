# Лабораторная работа 1 (Задачи 1–3)

## Задача 1 — идентификаторы потоков

### Сборка
```
g++ task1.cpp -o task1 -fopenmp
```

### Запуск
```
task1.exe <число_потоков>
```

Пример:
```
task1.exe 8
```
