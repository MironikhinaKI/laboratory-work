# Лабораторная работа 3 (Задача 5)

## Геометрический центр точек в 3D

### Сборка
```
g++ task5.cpp -o task5 -fopenmp
g++ generator.cpp -o generator
```

### Генерация файла с точками
```
generator.exe <файл> <число_точек>
```
Пример:
```
generator.exe crd_big.txt 1000000
```

### Запуск основной программы
```
task5.exe <файл> <число_потоков>
```
Пример:
```
task5.exe crd_big.txt 4
```

### Формат файла
Каждая строка — три числа (x, y, z):
```
1 2 3
4 5 6
```

### Версии программы
1. Параллельный цикл с `reduction`
2. Функциональная декомпозиция (`sections`)
