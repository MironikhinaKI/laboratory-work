# Лабораторная работа 3 (Задача 5)

## Геометрический центр точек в 3D

### Сборка (g++)
```
g++ generator.cpp -o generator -fopenmp
g++ task5.cpp -o task5 -fopenmp
```

### Генерация файла с точками
```
generator.exe
```
Программа запрашивает **число точек**. Например: `1000000`.
Создаёт файл `crd_big.txt` в текущей папке.

### Запуск
```
task5.exe
```
Программа запрашивает **число потоков**. Например: `4`.
Читает файл `crd_big.txt`, вычисляет геометрический центр двумя способами.

### Формат файла
Каждая строка — три числа (x, y, z):
```
1 2 3
4 5 6
```

### Версии программы
1. **reduction** — параллельный цикл с `#pragma omp parallel for reduction`
2. **sections** — функциональная декомпозиция (`#pragma omp parallel sections`)
