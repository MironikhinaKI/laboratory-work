# Лабораторная работа 2 (Задача 4)

## Умножение матриц

### Сборка
```
g++ task4.cpp -o task4 -fopenmp
```

### Запуск
```
task4.exe <rowsA> <n> <colsB>
```

Пример:
```
task4.exe 1000 500 1000
```
Где:
- `rowsA` — число строк матрицы A
- `n` — общее измерение (столбцы A = строки B)
- `colsB` — число столбцов матрицы B

Программа перемножает матрицы A (rowsA × n) и B (n × colsB), сравнивая время выполнения на 1, 2, 4, 8 потоках.
