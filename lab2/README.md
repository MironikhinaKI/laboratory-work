# Лабораторная работа 2 (Задача 4)

## Умножение матриц

### Сборка (g++)
```
g++ task4.cpp -o task4 -fopenmp
```

### Запуск
```
task4.exe
```

Программа запрашивает:
1. Число строк матрицы A (`rowsA`)
2. Общее измерение (`n` — столбцы A = строки B)
3. Число столбцов матрицы B (`colsB`)

Пример ввода:
```
1000
500
1000
```

Программа перемножает матрицы A (rowsA × n) и B (n × colsB), сравнивая время выполнения на 1, 2, 4, 8 потоках.

### Пример вывода
```
=== Результаты ===
Потоков: 1, время: 6.50496 сек
Потоков: 2, время: 3.18159 сек
Потоков: 4, время: 1.73685 сек
Потоков: 8, время: 1.29769 сек
```
